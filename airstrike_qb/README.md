# airstrike_qb

نظام ضربات صاروخية تكتيكي سينمائي لسيرفرات QBCore بواجهة HTML عسكرية وتعريب كامل.

## التركيب
1. ضع المجلد داخل `resources/[military]/airstrike_qb`
2. أضف `ensure airstrike_qb` داخل `server.cfg`
3. عدّل الإعدادات من `config.lua`

## التحكم
- `/strike` فتح واجهة HTML والتحكم الكامل
- `/strikecancel` إلغاء الضربة قبل التنفيذ
- من داخل الواجهة يمكنك:
  - اختيار نوع الضربة
  - تحديد الهدف
  - تنفيذ الضربة
  - إلغاء الضربة المعلقة
  - تشغيل/إيقاف الليزر
  - تشغيل/إيقاف الدرون
