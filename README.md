# דרך חדשה - ניהול עבודה והכנסות

יישום Windows Desktop מקצועי בעברית לניהול עבודה והכנסות של משתמש יחיד.

## יכולות עיקריות

- ממשק WPF מודרני בעברית, ימין-לשמאל, כולל מצב בהיר/כהה.
- מסד נתונים מקומי SQLite.
- לוח בקרה עם הכנסה יומית/שבועית/חודשית/שנתית, מספר משמרות ורשומות אחרונות.
- ניהול רשומות עבודה: תאריך, סוג משמרת, הכנסה, שעות, "מה עשינו היום", הערות ותמונה מצורפת.
- חיפוש לפי תאריך, מילת מפתח וסוג משמרת.
- דוחות יומיים, שבועיים, חודשיים וטווח מותאם אישית.
- ייצוא PDF מקצועי עם לוגו, שם החברה, מספור עמודים ופוטר בכל עמוד: `נוצר על ידי חמודה חאלד`.
- הדפסה מתוך האפליקציה.
- סטטיסטיקות וגרפים חודשיים/שנתיים.
- גיבוי ושחזור של מסד הנתונים.
- סקריפט Installer עבור Inno Setup.

## דרישות פיתוח

- Windows 10/11
- .NET 8 SDK
- Inno Setup 6 ליצירת מתקין

## הרצה מקומית

```powershell
cd src/DerechHadasha
 dotnet restore
 dotnet build
 dotnet run
```

## בניית התקנה

```powershell
cd src/DerechHadasha
 dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
 iscc ../../installer/DerechHadasha.iss
```

## לוגו

הלוגו מוגדר כווקטור XAML בתוך `src/DerechHadasha/Views/LogoMark.xaml`, כדי שהמאגר לא יכיל קבצים בינאריים. ניתן לעדכן את הצבעים/הצורה בקובץ זה, וה-PDF מצייר את אותו סגנון לוגו באופן וקטורי בקוד.
