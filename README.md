# Underground Silo Missile System (QBCore + qb-target)

سكريبت FiveM متكامل لإدارة صومعة إطلاق صواريخ من قاعدة تحت الأرض، مع تسلسل ميكانيكي مرئي (فتح البوابة -> رفع المنصة -> تدوير الذراع -> إطلاق).

## التركيب

1. ضع مجلد `underground_silo` داخل `resources/[local]`.
2. أضف `ensure underground_silo` في `server.cfg`.
3. تأكد من تشغيل:
   - `qb-core`
   - `qb-target`
4. عدّل الإحداثيات والمجسمات من `shared/config.lua` حسب الـ MLO عندك.

## المزايا

- دعم 4 أنواع صواريخ: Tactical / EMP / Chemical / Nuclear.
- تموضع دقيق مع Offset منفصل لكل نوع صاروخ.
- لوحة تحكم NUI عربية كاملة.
- مزامنة حالة الصومعة لجميع اللاعبين (مع GlobalState اختياري).
- مؤثرات خاصة:
  - EMP: فلاش وتعطيل إضاءة.
  - Chemical: سحابة غاز تسبب ضرر قريب.
  - Nuclear: فلاش قوي + اهتزاز + شكل سحابة فطرية بالجزيئات.
- تنظيف تلقائي للأجسام والمؤثرات بعد الإطلاق.

## التحكم

- الأمر: `/silo`
- أو التفاعل عبر `qb-target` عند لوحة التحكم.

## الصلاحيات

الوظائف المسموح لها موجودة في `Config.AuthorizedJobs`.
