# mos2 - FiveM Missile System (QBCore + qb-target)

نظام صواريخ سينمائي كامل داخل FiveM مبني على:
- **QBCore**
- **qb-target**
- **qb-menu**
- **qb-input**
- **progressbar**

## المزايا الأساسية

1. **التصنيع داخل المستودع** على مراحل مرئية (هيكل → رأس → صاروخ كامل).
2. **برمجة الهدف** عبر Waypoint أو أهداف جاهزة + تحديد مدى الطيران بالكيلومتر.
3. **طلب شاحنة نقل** وتحميل الصاروخ عليها مع Attach/Detach.
4. **تفاعلات qb-target شاملة** (حمل، تحميل، فك، برمجة، نقل، إطلاق).
5. **إطلاق سينمائي** (Countdown + صوت + دخان + Camera Shake).
6. **حركة صاروخ من 3 مراحل** (إقلاع عمودي، ميلان، منحنى نحو الهدف).
7. **اصطدام وانفجار** مع مؤثرات ضوئية واهتزاز كاميرا.
8. **Server Sync** لكل الحالات بحيث جميع اللاعبين يشاهدون نفس الحدث.
9. **Performance Friendly** عبر حلقات قصيرة ومدروسة بدون فيزياء ثقيلة.

## التثبيت

1. ضع المجلد داخل `resources/[local]/mos2`
2. أضف في `server.cfg`:
   ```cfg
   ensure mos2
   ```
3. تأكد من تشغيل الموارد التالية قبل `mos2`:
   - qb-core
   - qb-target
   - qb-menu
   - qb-input
   - progressbar

## الإعداد

كل الإعدادات موجودة في `config.lua`:
- موقع التصنيع (`Config.WarehouseCraftPoint`)
- موقع منصة الإطلاق (`Config.LaunchPad`)
- موديلات الصاروخ لكل مرحلة (`Config.MissileModels`)
- مدة المراحل والحركة (`Config.StageDurations`, `Config.Flight`)
- الأهداف الجاهزة (`Config.PredefinedTargets`)
- مؤثرات الصوت والدخان (`Config.Particles`, `Config.Sounds`)

## طريقة اللعب

1. توجه إلى نقطة المستودع.
2. اختر **ابدأ تصنيع صاروخ** من qb-target.
3. بعد الاكتمال استخدم:
   - **برمجة الهدف**
   - **تحميله على مركبة** أو `/missiletruck` لطلب شاحنة
   - **نقل للمنصة** (اختياري)
   - **إطلاق**

## ملاحظة مهمة

المشروع يستخدم **Object-based missile** وليس Vehicle، مع مزامنة على السيرفر وحركة سينمائية خفيفة.
