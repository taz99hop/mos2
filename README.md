# QBCore Ballistic Missile Script

## تركيب موديلات `cube` و `cylinder`

إذا سؤالك: **"شو أعمل هسا؟ وين أحط الموديلات؟"**
فالخطوات كالتالي:

1. انسخ ملفات الموديلات داخل مجلد `stream/` داخل نفس الريسورس:
   - `stream/cube.ydr`
   - `stream/cylinder.ydr`
   - وإذا عندك خامات:
     - `stream/*.ytd`
   - وإذا عندك تعريفات يتيب:
     - `stream/*.ytyp`

2. تأكد أن أسماء الموديلات داخل اللعبة هي نفسها المكتوبة في `config.lua`:
   - `cube`
   - `cylinder`

3. أضف الريسورس إلى `server.cfg`:
   ```cfg
   ensure mos2
   ```

4. تأكد من تشغيل الاعتماديات قبل السكربت:
   - `qb-core`
   - `qb-target`

5. أعد تشغيل السيرفر.

## ملاحظات مهمة

- إذا الموديل ما ظهر، السبب غالباً:
  - اسم موديل مختلف عن `cube` / `cylinder`.
  - الموديل ليس Stream-ready أو ناقص ملفات `.ytd`/`.ytyp`.
  - ترتيب `ensure` في `server.cfg` خطأ.
- الكود يستخدم `RequestModel` مع loop انتظار، لذلك عند توفر الموديل بشكل صحيح لن يختفي أثناء الاستخدام.
