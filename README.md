# MOS2 - نظام قيادة عسكرية متقدم لـ FiveM QBCore

هذا المورد يقدم نظام قيادة عسكرية واقعي جدًا لمنصة FiveM مع تركيز خاص على **فيزياء الصواريخ البالستية** بدل الانفجار المباشر.

## المميزات الأساسية

- دور قائد أعلى واحد مع صلاحيات إطلاق ومراقبة.
- وضع تجربة: يمكن تفعيل صلاحيات القائد لكل اللاعبين عبر `Config.TestingAllowAllPlayers = true`.
- تحديد الهدف عبر Waypoint (الخريطة) أو Laser (قابل للتوسعة من الواجهة/NUI).
- مسار صاروخي قوسي Ballistic Trajectory حقيقي:
  - سرعة ابتدائية عالية
  - صعود تدريجي
  - قمة مسار (Apex)
  - هبوط بالجاذبية
- دعم أنواع صواريخ متعددة:
  - HE
  - Long Range
  - Precision
  - Unguided
  - Cluster (انشطاري بمرئية انفصال فعلية)
- إطلاق متتالي مع تأخير عشوائي 1–2 ثانية.
- نظام دفاع جوي ذكي مع احتمال اعتراض وحساب معدل الإطلاق.
- نظام رادار حي: سرعة، اتجاه، ETA، وتتبع مباشر.
- تأثيرات إصابة استراتيجية:
  - محطات الكهرباء → Blackout تدريجي
  - الرادار → فقدان تتبع مؤقت
- نظام إنذار Incoming Missile مع ETA.
- الإطلاق يتم من منصات مدفعية ثابتة بإحداثيات محددة في `Config.LaunchPlatforms` (وليس من موقع اللاعب).
- تحسين الأداء عبر حدود عليا للصواريخ وعدد الشظايا.

## الهيكل

- `fxmanifest.lua` تعريف المورد وملفات التشغيل.
- `config.lua` كل الإعدادات القابلة للتخصيص.
- `shared/ballistics.lua` دوال الفيزياء البالستية.
- `server/main.lua` منطق القيادة والإطلاق والدفاع والرادار.
- `client/main.lua` العرض المرئي للصواريخ والـ NUI والتنبيهات.
- `html/*` واجهة قيادة عسكرية حديثة.

## كيف يعمل المسار البالستي؟

1. السيرفر يستقبل نقطة الإطلاق والهدف.
2. يتم حساب:
   - زمن الرحلة
   - متجه السرعة الابتدائية (vx, vy, vz)
   - زاوية الإطلاق
   - قمة المسار
3. في كل Tick:
   - تحديث الموضع بالمعادلة: `x = x0 + vx*t`, `z = z0 + vz*t - 0.5*g*t^2`
   - تحديث السرعة والاتجاه للرادار
4. عند الوصول أو الاصطدام:
   - انفجار حسب النوع
   - تفعيل تأثيرات الهدف

## Cluster Missile (الانشطاري)

- الصاروخ الأساسي ينطلق بقوس طبيعي كامل.
- عند بلوغ نسبة مسار/ارتفاع محدد يتم **انفصال مرئي** فعلي.
- يتم إنشاء 5–10 Sub-munitions بمسارات مستقلة مع جاذبية.
- الانتشار دائري + عشوائية خفيفة (تكتيكية).

## التركيب

1. ضع المجلد داخل `resources/[local]/mos2_command`.
2. تأكد من وجود `qb-core`.
3. أضف إلى `server.cfg`:

```cfg
ensure qb-core
ensure mos2_command
```

## التشغيل

- داخل اللعبة: `/milcmd`
- القائد يفتح الواجهة ويطلق المهمة بعد تحديد Waypoint.

## تخصيص سريع

من `config.lua` يمكنك تعديل:

- `CommanderCitizenId` لتحديد القائد.
- خصائص كل نوع صاروخ (السرعة، الانحراف، نصف قطر الانفجار).
- مناطق Safe/Combat.
- بطاريات الدفاع الجوي ونسبة الاعتراض.
- عدد الصواريخ/الشظايا الأقصى للأداء.

## ملاحظات تطوير مستقبلية

- ربط Laser Designator فعلي بسلاح/أداة مخصصة.
- ربط الضرر بمنظومة اقتصاد/خدمات السيرفر.
- إضافة لوحات قيادة متعددة المستويات (قائد عمليات، قائد دفاع).
- حفظ سجلات المهمات في قاعدة بيانات.
